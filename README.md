CheeseQuest — The Q-Learning Mouse



A multi-agent reinforcement learning maze project built with Python, Pygame, and NumPy.



Project Overview



CheeseQuest explores how intelligent agents can learn to navigate a maze using Reinforcement Learning. It combines Q-Learning agents with an A\* search agent to compare learning-based and pathfinding-based approaches.



Features



\- Two Q-Learning agents.

\- One A\* agent for comparison.

\- Shared Q-table for cooperative learning.

\- Competition and cooperation between agents.

\- Dynamic maze environment.

\- Visual maze simulation using Pygame.



Technologies



\- Python

\- Pygame

\- NumPy

\- Q-Learning

\- A\* Search Algorithm

\- Q Learning Algorithm

\- Reinforcement Learning



Installation



Clone the repository:



```bash

git clone https://github.com/Afaq-khadim/CheeseQuest-Q-Learning-Mouse.git

cd CheeseQuest-Q-Learning-Mouse

```



Install dependencies:



```bash

pip install -r requirements.txt

```



Run the Project



```bash

python "q-learning multiagent.py"

```



Learning Objectives



\- Understand Q-Learning in practical environments.

\- Explore cooperation through shared learning.

\- Compare Reinforcement Learning with A\* pathfinding.

\- Visualize multi-agent maze navigation.
